Configuration Google Suite

Pour relier ce site hébergé sur GitHub Pages à votre suite Google (Drive, Agenda, Tâches), renseignez simplement votre identifiant Client OAuth Google (100% gratuit).

Guide d'activation rapide en 2 minutes :
  1. Allez sur console.cloud.google.com
  2. Activez les API Drive, Calendar et Tasks
  3. Dans Identifiants > ID client OAuth (Application Web), ajoutez l'adresse de votre GitHub Pages dans « Origines JavaScript autorisées »
